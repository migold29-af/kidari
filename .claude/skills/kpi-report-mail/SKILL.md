# 월간 지표 리포트 요약 메일

플랫폼기획부가 매월 보내던 **[월간 지표 리포트] 메일**(기준: 26년 6월호, 2026-07-10 발송)을 같은 구조로 만든다.
결과물은 바로 보낼 수 있는 초안이다. 실제 발송은 사용자가 사내 메일(Terrace)에서 직접 한다.

## 파일

| 파일 | 역할 |
|---|---|
| `build_mail.py` | content.json → `mail.html`(붙여넣기용) · `mail.eml`(초안, PDF 첨부) · `mail.txt` 생성. 표준 라이브러리만 사용 |
| `config.json` | 매월 같은 값: 수신자(To/Cc), 제목 형식, 인트로·맺음말 문구, 대시보드 링크, 데이터분석 담당자 |
| `examples/2026-06.json` | 6월호 원본을 옮긴 예시. **문체·구조·분량의 기준** |

## 절차

1. **입력 확인.** 받을 수 있는 입력:
   - 컨플루언스 지표 분석 리포트 링크 → Atlassian MCP `fetch`에 ARI `ari:cloud:confluence:e266771a-4fdd-48be-b482-7b297b8940a8:page/<페이지ID>`를 넣어 읽는다. (`getConfluencePage`는 IP 제한으로 막힘. 페이지 ID는 URL `/pages/<숫자>/`)
   - Amplitude 대시보드 PDF → `pdftotext -layout`으로 수치를 읽고, 차트만 있는 페이지는 이미지로 확인
   - 붙여넣은 텍스트·표·캡처 이미지
   - 대상 월, 컨플루언스 링크, 첨부할 PDF가 빠졌으면 한 번에 모아서 묻는다. 대시보드 링크는 config 값을 기본으로 쓴다.
2. **수치 추출.** 리포트에 있는 숫자만 쓴다. 표마다 금월·전월·증감·증감율을 정리하고,
   증감율은 `python3`로 `(금월-전월)/전월`을 다시 계산해 리포트 값과 맞는지 확인한다. 안 맞으면 사용자에게 알린다.
3. **content.json 작성.** 저장 위치: `reports/kpi-mail/YYYY-MM/content.json` (저장소 루트 기준). 구조는 `examples/2026-06.json`을 따른다.
4. **생성.**
   ```bash
   python3 .claude/skills/kpi-report-mail/build_mail.py reports/kpi-mail/YYYY-MM/content.json --attach "<대시보드 PDF 경로>"
   ```
5. **검토.** `mail.html`을 Playwright로 스크린샷해 표·차트가 깨지지 않았는지 보고, 본문 수치를 원본과 한 번 더 대조한다.
6. **전달.** `SendUserFile`로 `mail.html`(render)과 `mail.eml`(attach)을 보내고, 채팅에는 아래만 짧게 적는다.
   - 제목, 핵심 요약 3줄
   - 확인이 필요한 항목(리포트에 없어 비운 값, 증감율 불일치, 역산한 차트 값 등)
   - 발송 방법: ① `mail.eml`을 Outlook 등에서 열면 수신자·첨부가 채워진 초안으로 열림 ② 사내 웹메일은 `mail.html`을 브라우저로 열어 본문만 복사해 에디터에 붙여넣고, 수신자·PDF는 직접 넣음
7. **커밋.** `content.json`, `mail.html`, `mail.txt`만 커밋한다(`.eml`, PDF는 `.gitignore` 대상).

## 메일 구조 (순서 고정)

1. 인트로 (config 고정 문구, 월만 빨간 굵은 글씨)
2. 링크: 대시보드 링크(+PDF 안내 문구, 첨부 파일명 자동 반영) / 컨플루언스 링크
3. `✅ 핵심 요약` — `summary`
   - `headline`: 한 문장 총평 (예: "6월은 전월(5월) 대비 핵심 지표 전반이 하락함")
   - `bullets`: 3개. ① 퍼널 4지표(방문·회차리스트 진입·열람·구매) 증감 ② 전환율 변화와 의미 ③ 유입 영역 특이사항
   - `charts`: 핵심 퍼널 유저수(금월 vs 전월) / `tables`: 지표·금월·전월 대비·비고
4. `📊 주요 지표` — `sections` (리포트 목차를 따르되 기본은 아래)
   - `1. 방문 대비 전환율`
   - `2. 회차 리스트 핵심 유입 영역` (Top10 표 + 차트)
   - `2-1. 내 서재 탭별` · `2-2. 웹툰 메인 구좌별` · `2-3. 검색 방법 별`(+검색어 Top 작품) · `2-4~` 리포트에 있는 하위 항목(배너·상단메뉴·이벤트페이지 등)
   - 용어는 리포트를 따른다 (10월부터 '회차리스트' → '작품상세')
   - 각 섹션: `bullets` 1~2개 + `callout` 1개(가장 중요한 시사점, 노란 하이라이트) + 차트/표 + `notes`
5. 맺음말 + 데이터분석 담당자 (config)

## 문체 규칙 (원본 메일 기준)

- 개조식 서술 종결: "~함", "~됨", "~보임", "~나타남", "~판단됨", "~필요". 경어체 문장은 인트로·맺음말에만 쓴다.
- 증감은 `%`(증감율)와 `%p`(비율 차이)를 구분한다. 전환율 변화는 항상 `%p`.
- 수치 → 해석 순서. 해석은 `→` 뒤에 굵게(`**...**`) 쓴다.
- 문단에서 가장 중요한 구절 하나만 `__...__`(굵게+밑줄)로 강조한다. 문단마다 최대 1개.
- 표 증감 칸은 `-2.85%`, `+7.69%`처럼 부호만 쓴다. 화살표(↓↑)는 스크립트가 붙인다.
- 눈에 띄는 행은 `{"cells": [...], "highlight": "down"}`(급감, 연분홍) 또는 `"up"`(유일 성장 등, 하늘색+굵게).
- 전월(직전 리포트)과의 흐름 비교("5월에는 ~였으나 6월에는 ~")는 직전 달 content.json이 있을 때만 쓴다. 없으면 쓰지 않는다.

## 정확성 규칙

- **리포트에 없는 원인은 단정하지 않는다.** 원인 추정이 필요하면 "~ 변경 사항이 있었는지 점검이 필요해 보임"처럼 확인 요청으로 쓴다.
- 리포트에 없는 숫자는 만들지 않는다. 값이 없으면 `-`로 두고 채팅에서 알린다.
- 차트에 전월 절대값이 없어 금월 값과 증감율로 역산했다면 그 차트에 `"show_values": "curr"`를 넣어 역산값이 표시되지 않게 하고, 채팅에서 역산했다고 알린다.
- 작가 실명·연락처, 계약 조건, 개인 휴대폰 번호는 본문과 config에 넣지 않는다. 작품명은 그대로 써도 된다.

## content.json 요소 요약

```jsonc
{
  "year": 2026, "month": 7, "prev_month": 6,
  "confluence_url": "...", "confluence_title": "7월 지표 분석 리포트",
  "dashboard_url": "(생략 시 config 값)",
  "subject": "(생략 시 config 형식으로 자동 생성)",
  "notice": "(선택) 리포트 상단 📢 안내사항 — 링크 아래 주황 박스",
  "footnote": "(선택) 데이터 기준 각주 — 맺음말 위 이탤릭",
  "summary": { "headline": "", "bullets": [], "charts": [], "tables": [], "images": [] },
  "sections": [{
    "title": "1. 방문 대비 전환율",
    "bullets": [], "callout": "",
    "charts": [{ "title": "", "labels": [], "prev": [], "curr": [], "unit": "%(선택)", "show_values": "both|curr|none" }],
    "tables": [{ "columns": [], "header_groups": [["영역",1],["회차 리스트 유입자 수",2]], "first_col_center": true, "rows": [] }],
    "images": [{ "path": "content.json 기준 상대경로", "width": 720 }],
    "notes": [{ "label": "금월 검색어 Top 주요 작품", "text": "" }]
  }]
}
```

`images`는 리포트 차트 캡처를 그대로 넣고 싶을 때 쓴다(EML에 인라인 이미지로 들어감).
